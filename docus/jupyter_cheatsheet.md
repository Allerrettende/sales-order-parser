# 掌握核心快捷键：操作快人一步
VS Code 的 Jupyter Notebook 支持大部分原生快捷键，熟练使用它们能极大提升编码效率。

快捷键主要分为两种模式，用法和原生 Jupyter 基本一致：

模式切换：按 Esc 进入命令模式（单元格边框为蓝色），按 Enter 进入编辑模式（边框为绿色）。

命令模式 (Command Mode)：

A / B：在当前单元格上方/下方插入新单元格。

M / Y：将当前单元格切换为 Markdown / 代码单元格。

DD (连按两次 D)：删除当前单元格。

Ctrl + Enter：运行当前单元格。

Shift + Enter：运行当前单元格并选中下一个。

Alt + Enter：运行当前单元格并在下方插入一个新单元格。

编辑模式 (Edit Mode)：

Tab：代码自动补全或缩进。

Ctrl + /：注释/取消注释选中的代码行。



# 利用VS Code独家利器：调试与数据查看
除了快捷键，VS Code 还提供了超越原生 Notebook 的强大功能，这是高效使用的关键。
## 1.	变量资源器与数据查看器 (Variables Explorer & Data Viewer)：  
这是 VS Code 的杀手锏功能。运行代码后，点击工具栏的“变量”按钮，可以清晰地看到当前所有变量的列表和值。   
对于 DataFrame 这样的复杂数据，双击变量即可在“数据查看器”中打开，支持搜索和过滤，查看大表格数据非常方便。 
## 2.	内置调试器 (Debugger)： 
告别 print() 调试法，你可以像调试普通 Python 脚本一样，在 Notebook 中设置断点、单步执行、观察变量状态。
o	调试整个 Notebook：在命令面板（Ctrl+Shift+P）中运行 Jupyter: Debug Current File in Python Interactive Window。
o	调试单个单元格：点击单元格上方出现的 "Debug Cell" 按钮即可。


- Notebook只负责调用函数和看结果，代码逻辑都在.py文件里
- 修改函数只需要改.py文件，所有Notebook自动生效
- 部署时直接用src/目录，Notebook都不用动
