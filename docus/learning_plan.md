## 第二阶段（第 4-6 周）项目实战 

暂定以下三个项目。 

### 第四周：商业数据分析实战项目   
学习模式 ：每日 4 小时全程项目实战，无碎片化理论学习，专注落地完整商业项目   
核心目标 ：熟练掌握商业数据分析全流程，涵盖数据读取、清洗、统计分析、可视化展示、成果输出全环节   
最终输出项目 ：Ecommerce Analysis 电商数据分析完整实战项目 

### 五周：AI 实战项目开发 
学习模式 ：课程学习+项目实战双向结合，上午完成 AI 进阶课程学习，下午全力落地项目开发   
核心项目 ：AI 金融分析助手   
项目流程 ：股票原始数据采集 → Python 计算金融指标 → LLM 大模型智能分析 → 自动生成专业分析报告   
核心技术栈 ：Python、Pandas、大模型 API 调用、Prompt 工程优化 

### 第六周：金融建模与优化项目   
学习模式 ：AI 辅助，ChatGPT, Gemini   
核心项目 ：美式期权 Monte Carlo + 风险分析，或投资组合风险分析。   
项目流程 ：Monte Carlo Simulation ，Greeks ，参数敏感性分析   
核心技术栈 ：NumPy, SciPy
